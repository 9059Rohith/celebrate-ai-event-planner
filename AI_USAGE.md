# Codex / AI Usage

Codex assisted with interpreting Challenge 5; designing the Next.js application; implementing intake, planning controls, persistence and domain engines; adding server-side OpenAI integration; writing unit, component, property, API and browser regressions; building evaluation tooling; debugging hydration and deployment caching; and preparing documentation and demo artifacts.

The application uses the official OpenAI SDK for optional plan enhancement, ideas and grounded chat. Structured output is validated, repair attempts are bounded and separately budgeted, and domain engines own money/date invariants. Proposed mutations require explicit acceptance.

Offline evaluation executes the actual deterministic engine. MSW tests exercise provider transport using synthetic responses. Neither is a live model benchmark. Production credentials, live responses and judge results require separate verification; credentials, subjective scores and competition rankings are never fabricated.

Screenshots and demo video show the real application with synthetic event details. Template source labels remain visible when the provider is unavailable. No real vendor contacts or private event records are included.
